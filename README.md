**A experiência web 3D mais impressionante que você verá hoje.** Partículas neon interativas em tempo real, conexões dinâmicas, glassmorphism premium e estética cyberpunk impecável — tudo em **um único arquivo**.

## ✨ Destaques de Perfeição

- **2600+ partículas** com sistema de conexões otimizado (até 280 linhas visíveis)
- Interação fluida com **mouse + touch** (mobile first)
- Animações suaves em 60fps com requestAnimationFrame
- Efeitos de glow, floating e parallax mouse-driven
- Design glassmorphic com backdrop blur e gradientes neon
- Totalmente responsivo e otimizado para performance
- Zero dependências pesadas — Three.js via CDN rápido

## 🚀 Como Executar

```bash
git clone https://github.com/Darlan0786/Site-3D-testing.git
cd Site-3D-testing
# Abra index.html no navegador ou use Live Server
```

## Deploy Instantâneo no Vercel

1. Vá para [vercel.com](https://vercel.com) e importe o repositório
2. Framework Preset: **Other**
3. Build Command: `echo "No build needed"`
4. Output Directory: `.`
5. Deploy — seu site estará online em segundos!

## Tecnologias Utilizadas

- **Three.js** (r134) — WebGL 3D
- Pure HTML5, CSS3 com variáveis customizadas
- Vanilla JavaScript com otimização extrema
- Font Awesome icons
- Glassmorphism + Cyberpunk Neon
